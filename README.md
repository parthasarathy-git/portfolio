# Portfolio

React + Vite + TypeScript + Tailwind CSS. All content lives in `src/data.ts`.

```bash
npm install
npm run dev      # local preview
npm run build    # type-check and build to dist/
```

## Deploy to GitHub Pages
1. Push this folder to a GitHub repo on the `main` branch.
2. In the repo, open Settings, then Pages, and set Source to **GitHub Actions**.
3. Every push to `main` builds and publishes the site (see `.github/workflows/deploy.yml`).
